Zadanie testowe
Twoim zadaniem jest zbudowanie aplikacji webowej PDF Insight, która wczytuje plik PDF, tworzy jego krótkie podsumowanie i zamienia treść w uporządkowane dane JSON. Aplikacja ma być publicznie dostępna na GitHub Pages.
Szczegółowy brief (zakres, stack, schemat danych, standardy i kryteria oceny) znajdziesz w załączniku Brief_Vibe_Coder_PDF_Insight.pdf. Do testów możesz użyć dołączonego pliku Test_PDF_Insight_umowa_14-2026.pdf.

Do oddania: link do publicznego repozytorium GitHub (z plikiem AI_LOG.md) oraz link do działającego demo na GitHub Pages. W formularzu wklej link do repozytorium w polu „Link do zadania testowego”, a link do demo w polu „Komentarz do zadania”.
